# solc 0.1.6 (soljson)

`soljson-v0.1.6+commit.d41f8b7c.js` is the Solidity 0.1.6 compiler built for JavaScript, unchanged from
[ethereum/solc-bin](https://github.com/ethereum/solc-bin). It is kept here so the recipes in this
